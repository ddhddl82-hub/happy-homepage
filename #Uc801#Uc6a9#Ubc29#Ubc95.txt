행복한 홈페이지 CMS 연결 복구본

수정된 핵심 파일
- index.html
- content-manager.js

적용 방법
1. GitHub happy-homepage 저장소를 엽니다.
2. 압축을 풀어 나온 파일과 폴더를 저장소 최상단에 그대로 업로드합니다.
3. 같은 이름의 파일 덮어쓰기를 확인하고 Commit changes를 누릅니다.
4. 약 1~3분 뒤 홈페이지를 Ctrl+F5로 새로고침합니다.

이번 수정으로 연결되는 관리자 항목
- 메인 상단 문구
- 메인 제목
- 소개 문구
- 대표 사진
- 원장 인사 제목과 본문
- 원장 인사 사진
- 서명
- 보육철학 카드
- 특별활동
- 공간 소개의 공간명·설명·사진·순서
- 활동 갤러리의 제목·설명·사진·순서

중요
- 기존 관리자 저장 내용은 같은 브라우저의 localStorage에 남아 있습니다.
- GitHub 주소가 같다면 새 파일 적용 후 관리자에서 저장한 내용이 홈페이지에 다시 표시됩니다.
- 관리자에서 저장한 뒤 메인 홈페이지 탭을 새로고침해야 합니다.
