행복한프뢰벨어린이집 홈페이지 공용 연동 적용 순서

중요
- 기존 홈페이지 디자인과 기능은 유지되어 있습니다.
- 먼저 현재 PC 관리자에서 “설정 백업파일 받기”를 눌러 백업해 두세요.
- GitHub 토큰과 ADMIN_KEY는 파일이나 채팅에 적지 마세요.

1. Cloudflare Worker 코드 교체
1) Cloudflare → Workers & Pages → happy-homepage-upload → Edit code
2) ZIP 최상단의 Cloudflare-Worker.js를 메모장으로 엽니다.
3) 파일 내용을 전부 복사합니다.
4) Cloudflare 코드 편집기의 기존 코드를 전부 지우고 붙여넣습니다.
5) Deploy를 누릅니다.
6) 아래 주소를 엽니다.
   https://happy-homepage-upload.ddhddl82.workers.dev/health
7) configured가 true인지 확인합니다.
   {"ok":true,"service":"happy-homepage-upload","configured":true}

2. GitHub 홈페이지 파일 교체
1) 이 ZIP을 풉니다.
2) happy-homepage-main 폴더 안의 파일과 폴더 전체를 선택합니다.
3) GitHub의 ddhddl82-hub/happy-homepage 저장소 최상단에 업로드합니다.
4) Commit changes를 누릅니다.
5) GitHub Pages 반영까지 약 1~3분 기다립니다.

3. 현재 PC에만 저장된 내용을 모든 기기에 공개
1) 반드시 지금까지 수정하던 같은 PC와 같은 브라우저에서 아래 주소를 엽니다.
   https://ddhddl82-hub.github.io/happy-homepage/admin/
2) 백업·복원 메뉴로 들어갑니다.
3) Worker 주소가 아래와 같은지 확인합니다.
   https://happy-homepage-upload.ddhddl82.workers.dev
4) Cloudflare에 Secret으로 저장한 ADMIN_KEY 값을 관리자 비밀번호 칸에 입력합니다.
5) “연결 확인”을 누릅니다.
6) “연결 정상”이 표시되면 상단의 “모든 기기에 공개”를 누릅니다.
7) 사진 업로드와 content.json 저장이 끝날 때까지 창을 닫지 않습니다.
8) “공개 완료”가 표시되면 1~3분 뒤 휴대폰에서 홈페이지를 새로 엽니다.

4. 다른 컴퓨터에서 관리
- 같은 관리자 주소로 들어가면 현재 공개된 data/content.json을 자동으로 불러옵니다.
- 수정 후 “모든 기기에 공개”를 누르면 모든 기기에 동일하게 반영됩니다.
- ADMIN_KEY는 브라우저 탭을 닫으면 다시 입력해야 합니다.
